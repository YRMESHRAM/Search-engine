# Trie-Based Search Engine in C

This project implements a **Trie-based Search Engine** in **C**. It offers functionalities for inserting, searching, deleting words, providing auto-complete suggestions, and displaying all stored words. The system is interactive and case-insensitive, making it easy to manage and explore stored words.

---

## Features

- **Insert Words**: Add words to the Trie along with their positions.
- **Search Words**: Check if a word exists in the Trie and retrieve its position.
- **Delete Words**: Remove words from the Trie.
- **Auto-Complete**: Get suggestions for words based on a prefix.
- **Display All Words**: View all stored words in the Trie.
- **Interactive Menu**: Perform all operations interactively from a menu-driven interface.
